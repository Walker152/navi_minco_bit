# CloudLab Studio 点云与地图编辑器

CloudLab Studio 是面向 RoboMaster 导航地图制作的可视化点云编辑工具。它以单个 HTML 页面运行，主要用于点云去噪、区域裁剪、坡面与几何语义分割，以及生成 Nav2 PGM、二维 Signed ESDF、Elevation Map 和 ROGMap 可用 PCD。

编辑器不依赖 ROS 2 节点即可工作。ASCII/Binary PCD 和 XYZ 可以直接在浏览器中处理；`binary_compressed` PCD、Open3D 统计滤波和精确法向分割需要启动可选的本地后端。

## 功能概览

- 可缩放、可折叠的处理管线和参数面板。
- 透视、顶视、前视和侧视点云查看。
- 刚体平移与 Roll/Pitch/Yaw 旋转。
- 体素降采样、半径离群点滤波和 Open3D 统计离群点滤波。
- DBSCAN 噪点/小聚类移除，并把清理结果直接载入三维视图。
- HWS 风格离线多帧射线穿透动态体素去除，支持统计与聚类后处理。
- PCD→STL 的视觉/碰撞预设、Poisson/Ball Pivoting 选择和网格覆盖预览。
- STEP/STP→PCD，本机路径读取、毫米到米缩放和可选采样点数。
- 轴对齐/旋转三维裁剪盒、矩形选区和多边形套索裁剪。
- 地面、坡面、墙体、障碍物、噪声等几何语义分类与人工修订。
- 根据语义生成 Nav2 PGM/YAML，并支持外围未知区域自动裁边和局部空洞估计。
- 导出二维 Signed ESDF PCD、Elevation PCD/YAML 和处理后的 ROGMap PCD。
- 处理历史、撤销/重做、地图覆盖预览和工程参数 JSON 导出。

## 按任务选择功能

| 目标 | 页面入口 | 是否需要后端 | 主要输出 |
|---|---|---:|---|
| 浏览、变换、裁剪普通 PCD/XYZ | 文件与工程、坐标变换、区域裁剪 | 否 | `cloudlab_processed.pcd` |
| 统计滤波、DBSCAN 小簇清理 | 去噪与聚类 | 是 | 清理后的 PCD |
| 去除多帧建图中的动态残影 | 动态障碍去除 | 是 | 合并并清理后的 PCD |
| 点云快速重建表面 | PCD 转 STL | 是 | `cloudlab_visual.stl` 或 `cloudlab_collision.stl` |
| STEP/STP 均匀采样为点云 | 文件与 STEP | 是，并需要 `freecadcmd` | 可继续编辑和导出的 PCD |
| 制作 Nav2/ROGMap 地图 | 坡面分割、语义修订、地图生成、验证与导出 | 普通 PCD 可不需要 | PGM/YAML、PCD、ESDF、Elevation |

浏览器模式负责交互、预览和基础算法；Open3D 后端负责压缩 PCD、邻域算法、聚类、动态去除和网格/CAD 转换。后端不会自动修改仓库文件，所有结果都需要在页面中确认后下载。

## 快速启动

### 纯浏览器模式

终端 1，在仓库根目录启动静态页面：

```bash
python3 -m http.server 8080 --directory src/utils/pcd_trans
```

浏览器打开：

```text
http://127.0.0.1:8080/visual_point_cloud_lab.html
```

也可以直接打开 `visual_point_cloud_lab.html`，但使用本地 HTTP 服务通常能避免浏览器对 `file://` 页面、Worker 或文件下载的额外限制。

> [!NOTE]
> 页面通过 CDN 加载 React、Three.js、Babel、Tailwind 和图标资源。首次打开需要网络；资源已经被浏览器缓存后可继续使用缓存版本。

### 可选 Open3D 后端

后端用于：

- 读取 `binary_compressed` PCD。
- 执行 Open3D Statistical Outlier Removal。
- 使用 Open3D 邻域法向进行语义分割。
- 执行聚类、离线动态去除和 PCD 表面重建。
- 配合 FreeCAD 命令行把 STEP/STP 三角化后采样为点云。

需要 Python 3、NumPy 和 Open3D；STEP/STP 转换另外要求系统能够执行 `freecadcmd`。依赖缺失时可根据当前 Python 环境安装：

```bash
python3 -m pip install numpy open3d
```

先确认 Python 和 FreeCAD 命令是否可用：

```bash
PYTHONPATH=src/utils/pcd_trans python3 -c \
  "from point_cloud_lab_server import load_open3d; print(load_open3d().__name__)"
command -v freecadcmd  # 只有 STEP/STP 转换需要
```

终端 2，在仓库根目录启动后端：

```bash
python3 src/utils/pcd_trans/point_cloud_lab_server.py
```

服务默认只监听 `127.0.0.1:8765`。页面右上角显示“Open3D 后端在线”后，压缩 PCD、统计滤波和后端法向分割会自动可用。

后端支持 `--host` 和 `--port`，但当前页面固定连接 `127.0.0.1:8765`；正常本机使用不要修改这两个参数。

可以检查服务状态：

```bash
curl --noproxy '*' http://127.0.0.1:8765/health
```

除非明确需要远程访问，否则不要把后端绑定到公网地址。后端接受点云文件和二进制 XYZ 数据，不提供身份认证。

## 支持的数据格式

| 类型 | 浏览器 | Open3D 后端 | 说明 |
|---|---:|---:|---|
| ASCII PCD | 支持 | 支持 | 自动识别 XYZ 和可选 intensity |
| Binary PCD | 支持 | 支持 | 小端字段解析 |
| Binary Compressed PCD | 不支持 | 支持 | 页面检测到后自动交给后端 |
| XYZ / TXT | 支持 | 不需要 | 每行前三列为 X、Y、Z |
| PGM | 支持 | 不需要 | 用于加载现有地图并与点云覆盖检查 |
| STEP / STP | 不直接上传 | 支持 | 后端按本机绝对路径读取，经 FreeCAD 三角化后均匀采样 |
| STL | 生成与预览 | 支持 | Binary STL；可选择视觉或碰撞网格预设 |

工具以连续 `Float32Array` 保存完整点云，按约 200 万点的离线编辑目标设计。为了控制 GPU 压力，视口可能只渐进显示部分点，但处理和导出仍针对完整数据。处理百万级点云时建议优先体素降采样，再运行邻域滤波或分割。

## 常用任务用法

### 清理单个 PCD 并导出

1. 在“文件与工程”导入 PCD。
2. 查看点数、XYZ 范围和单位；ROS/Gazebo 场地通常应使用米和 Z-up。
3. 在“去噪与聚类”先做体素降采样，再按需要使用统计滤波或 DBSCAN。
4. 在三维视图确认细小障碍、坡面和墙角没有被误删。
5. 打开“验证与导出”，选择 Binary 或 ASCII PCD。

`eps`、体素尺寸和最小簇点数依赖点密度，不存在适合所有场地的固定值。建议先在副本上用保守参数处理，并通过撤销/重做比较前后差异。

### 清理多帧动态残影

1. 准备 `poses.txt` 与逐帧 `frame_N.pcd`，帧数和位姿行数必须一致。
2. 启动 Open3D 后端，在“动态障碍去除”填写后端机器上的数据目录绝对路径。
3. 设置射线体素、穿透阈值、抽样步长和最大距离。
4. 点击“运行并载入清理结果”，检查移除点数和三维覆盖。
5. 需要时继续统计/聚类后处理，然后导出 PCD。

只有一份合并 PCD 时不能恢复射线时序，只能做近似统计或聚类清理。

### PCD 快速生成 STL

1. 导入并清理点云，确认单位、轴向和原点。
2. 打开“PCD 转 STL”，先用较大的体素和较低目标面数快速预览。
3. 视觉模型通常选择 Poisson；希望保留真实开口时可尝试 Ball Pivoting。
4. 对照点云检查地面、坡道、台阶、墙体、孔洞和模型边界。
5. 下载视觉或碰撞 STL。

这是通用表面重建，不是 CAD 恢复。扫描缺失、法向不一致、薄板上下表面过近时，Poisson 可能补出假面、坑洞或波浪地面；自动简化也可能把薄地面压向中间高度。场地 collision 必须经过网格修复和 Gazebo 车辆接触验收，不能只凭“成功生成 STL”判定可用。

### STEP/STP 转 PCD

1. 确保后端机器能够执行 `freecadcmd`。
2. 在“文件与 STEP”填写 STEP/STP 的本机绝对路径。
3. 选择采样点数、单位缩放、线性/角度偏差和 FreeCAD 内存上限。
4. 点击“转换并载入点云”，确认边界和单位后从“验证与导出”导出 PCD。

毫米制 CAD 通常使用 `unit_scale=0.001`。采样点数只影响最终点云密度，不会降低 FreeCAD 解析大型装配拓扑时的内存占用；超大装配应先拆分、简化或在内存更大的机器上预三角化。

### 生成 Nav2 PGM/YAML

1. 完成滤波、裁剪和坐标对齐。
2. 运行坡面分割，并人工修订地面、坡面、墙体、障碍物和噪声标签。
3. 在“地图生成”设置分辨率、投影范围、障碍高度和补全选项。
4. 检查栅格预览中占据、空闲、未知区域及 origin。
5. 在“验证与导出”下载 PGM/YAML，并在 RViz 中与原始点云覆盖验收。

## 视图操作

| 操作 | 鼠标/按键 |
|---|---|
| 旋转视图 | 左键拖动 |
| 平移视图 | 中键或右键拖动 |
| 缩放视图 | 滚轮 |
| 矩形框选 | 进入“框选”，在顶视图点击两个对角点 |
| 多边形套索 | 进入“套索”，依次点击至少三个顶点 |
| 退出选区 | `Esc`、再次点击当前选区工具，或“退出并清空选区” |

执行选区裁减或语义赋值后，编辑器会自动退出选区并恢复左键旋转。矩形和套索均使用世界坐标系 XY 平面选择点，建议先切换到顶视图。

## 推荐处理流程

建议按照左侧管线从上到下处理：

1. **文件与工程**：导入 PCD、XYZ 或 TXT，确认点数和坐标范围。
2. **坐标变换**：统一点云方向、地图原点和 Z-up 坐标。
3. **去噪与聚类**：先体素降采样，再执行半径、统计或 DBSCAN 小簇清理。
4. **动态障碍去除（可选）**：对保留逐帧扫描和位姿的数据运行射线穿透过滤。
5. **区域裁剪**：通过三维裁剪盒、矩形或套索保留需要的赛场区域。
6. **坡面分割**：设置局部网格、坡度、粗糙度和墙体高度差，生成初始语义。
7. **语义修订**：框选误分类区域并人工赋值。
8. **PCD 转 STL（可选）**：生成视觉模型或简化碰撞模型并覆盖预览。
9. **地图生成**：设置 Nav2 投影范围、分辨率、语义补全和裁边选项，生成预览。
10. **验证与导出**：检查点云/PGM 覆盖关系，导出 PCD、STL、PGM、ESDF 或 Elevation。

> [!IMPORTANT]
> 体素降采样、半径滤波和统计滤波会改变点集，并将语义标签重置为“未分类”。因此应先完成滤波和裁剪，再进行语义分割与人工修订。

## 去噪与裁剪

### 体素降采样

`Leaf Size` 表示体素边长。每个体素输出一个平均点。较大的 Leaf Size 会显著减少点数，但也会损失台阶、坡面边缘和窄障碍物细节。

### 半径离群点

对每个点检查给定半径内的邻居数，低于“最少邻居数”的点会被删除。该操作在高密度百万点云上计算量较大，建议在体素降采样之后执行。

### Open3D 统计离群点

根据邻域平均距离和标准差倍率删除统计异常点。只有后端在线时可用。

### DBSCAN 小簇清理

`eps` 是邻域半径，核心点邻居数决定稠密区域判定，最小保留簇点数用于删除零散的小物体。该操作会同时删除 DBSCAN 噪点。百万点云应先做体素降采样，否则聚类会消耗较多内存和时间。

## 离线动态障碍去除

“动态障碍去除”读取服务器本机目录，目录结构必须是：

```text
mapping_dataset/
├── poses.txt
├── frame_0.pcd
├── frame_1.pcd
└── ...
```

`poses.txt` 每个非空行对应一帧，接受 `x y z qx qy qz qw` 或 `SE3(x,y,z,qx,qy,qz,qw)`。工具先按位姿把各帧变换到世界系，再用 3D DDA 遍历传感器原点到激光端点之间的体素；被射线穿透次数超过阈值的已占据体素视作动态残影并删除。其后可以继续做体素、统计和 DBSCAN 后处理。

只有一个已经合并的 PCD（例如 `111.pcd`）时，传感器原点、帧顺序和射线关系已经丢失，不能执行真实的穿透统计。此时只能使用统计滤波和聚类做近似噪声清理。

## PCD 转 STL

“PCD 转 STL”提供两套默认值：

| 预设 | 默认体素 | Poisson depth | 目标三角形 | 用途 |
|---|---:|---:|---:|---|
| 视觉模型 | 0.03 m | 9 | 500,000 | Gazebo 可视资源、外观检查 |
| 碰撞模型 | 0.06 m | 8 | 80,000 | 简化碰撞几何、降低仿真负载 |

Poisson 更容易生成连续/封闭表面，Ball Pivoting 更倾向保留原始孔洞。大于 150,000 个预处理点时，工具使用线性的 +Z 半球法向定向，避免 Open3D 的全局一致法向传播在场地级点云上耗时过长。生成后视图会覆盖显示法向着色网格，确认尺度、地面和边界无误后再下载 STL。

“视觉/碰撞预设”只代表面数和重建参数不同，不代表结果已经满足 Gazebo 物理要求。碰撞模型至少还要检查：平地平整度、坡面连续性、台阶高度、墙体边界、孔洞、非流形面、自相交和坐标尺度。不建议直接把高面数视觉 STL 同时用作碰撞体，也不建议把存在坑洞或薄板塌缩的简化结果投入车辆仿真。

## STEP / STP 转 PCD

在“文件与 STEP”中填写后端所在机器的 STEP/STP 绝对路径和目标采样点数。FreeCAD 先把 CAD Shape 三角化，Open3D 再按三角面面积均匀采样并输出点云。默认 `unit_scale=0.001`，用于把常见的毫米制 STEP 转成 ROS/Gazebo 使用的米制坐标。

大型装配建议先用 5–20 mm 线性偏差和较少点数做粗验收；采样点数只控制最终 PCD 密度，不会降低 FreeCAD 读取装配拓扑本身的内存。FreeCAD 子进程默认限制为 6 GiB，避免超大装配耗尽系统内存；内存充足的机器可以调高，设为 0 表示关闭限制。网页传递的是本机路径，不会把 GB 级 STEP 经浏览器上传到后端。

### 三维裁剪盒

可以分别设置 X/Y/Z 最小值和最大值，并绕 Z 轴旋转裁剪盒。选择“保留框内点”时删除框外点；取消后则删除框内点。

### 可视选区裁剪

矩形选区需要两个对角点，多边形套索需要至少三个顶点。可选择保留选区或删除选区。操作完成后会清空选区并恢复视图导航。

## 语义分割

语义类别及其地图含义：

| 类别 | PGM 投影语义 |
|---|---|
| 未分类 | 高于障碍高度阈值时为占据，否则为空闲 |
| 地面 | 空闲 |
| 坡面 | 空闲 |
| 墙体 | 占据 |
| 障碍物 | 占据 |
| 噪声 | 忽略，不参与投影 |

浏览器模式根据局部高程连续性、坡度、粗糙度和高度跨度分类。后端在线时使用 Open3D 邻域法向增强分类。自动结果应通过语义着色和顶视图复核，关键墙面、坡面边界及场地外沿建议人工修订。

## Nav2 PGM/YAML 生成

### 投影规则

点云按世界坐标 XY 投影到栅格，同一栅格内占据优先于空闲。输出采用 Nav2 trinary 约定：

| PGM 值 | 含义 |
|---:|---|
| `0` | 占据 |
| `254` | 空闲 |
| `205` | 未知 |

PGM 数据按图像顶行到末行存储，YAML origin 保持 ROS 地图左下角坐标。自动裁边后编辑器会同步修正 origin，不能继续使用裁边前的原点值。

### 范围与外围空白

- “适配当前点云范围”会把 Min/Max XYZ 更新为当前处理后点云边界。
- “自动裁掉外围未知区域”会删除地图四周完全未知的行列。
- “外围保留边距”控制裁边后保留的未知缓冲，默认 `0.25 m`。
- 地图预览保持真实宽高比，不再强制拉伸为固定比例。

### 语义空洞估计

“根据地面/坡面补充局部空洞”只使用已经标记为地面或坡面的栅格作为空闲种子：

- 默认补全半径为 `0.25 m`。
- 默认障碍保护距离为 `0.15 m`。
- 只补已有观测包围框内部的邻近未知栅格。
- 不覆盖墙体或障碍物，也不会向观测区域外扩张。
- 大范围未观测区域继续保持未知。

预览中的青色区域是估计空闲格，导出 PGM 后按 `254` 空闲值保存。该功能适合补充点密度不足造成的小孔，不适合推断墙后、遮挡区或完全未扫描区域。

### 导出文件

点击“导出 PGM + YAML”会下载：

- `cloudlab_map.pgm`
- `cloudlab_map.yaml`

浏览器可能要求允许一次下载多个文件。导出后建议核对 YAML 中的 resolution、origin 和阈值，再放入 `navi2_bringup/maps` 使用。

## ESDF、Elevation 与 PCD 导出

### 二维 Signed ESDF

ESDF 从当前 PGM 计算二维欧氏距离场，输出 `cloudlab_esdf.pcd`：

- 字段为 `x y z intensity`。
- 空闲侧距离为正，占据内部距离为负。
- `intensity` 保存以米为单位的 signed distance。
- 最大距离由“ESDF 最大距离”限制。
- 当前导出把未知栅格视为非占据区域；用于安全规划前应确认这符合下游约定。

格式与 `src/utils/pcd2esdf` 使用的 Binary PCD 结构保持一致。

### Elevation Map

Elevation Map 按 XY 栅格聚合 Z 值，可选择：

- `min`：最低点。
- `median`：中位数。
- `p90`：90% 分位。
- `max`：最高点。

导出文件为 `cloudlab_elevation.pcd` 和 `cloudlab_elevation.yaml`。

### ROGMap 点云

可以把当前处理结果导出为 Binary 或 ASCII `cloudlab_processed.pcd`。需要保留人工语义时，应同时保存工程参数与处理记录；当前 XYZ PCD 导出不写入语义字段。

### 工程审计 JSON

`cloudlab_project.json` 保存源文件名、点数、处理历史、地图参数和分割参数，用于记录本次地图制作过程。它不是完整点云工程快照，重新编辑时仍需导入原始或处理后的 PCD。

## 常见问题

### 导入点云时报 `window is not defined`

当前 Worker 使用唯一的 `cloudlab-core` 脚本创建，不应执行页面 UI 代码。出现旧错误时先强制刷新页面或清除该页面缓存，确认浏览器加载的是当前版本。

### `binary_compressed` PCD 无法导入

确认 Open3D 后端已经启动，页面显示“Open3D 后端在线”，并检查：

```bash
curl --noproxy '*' http://127.0.0.1:8765/health
```

### 裁减后左键仍在框选

当前版本在裁减完成后会自动退出选区。也可以按 `Esc` 或点击“退出并清空选区”。如果行为没有更新，请强制刷新浏览器缓存。

### PGM 中有效地图很小、外围空白很多

依次检查：

1. 点云是否仍包含远距离离群点。
2. 点击“适配当前点云范围”。
3. 开启“自动裁掉外围未知区域”。
4. 调小外围保留边距。
5. 对点云完成语义分割后，再按需开启局部空洞估计。

不要把所有未知区域直接改为空闲，否则可能让 Nav2 把墙后或未扫描区域当作可通行空间。

### 生成地图后没有语义补全

只有“地面”和“坡面”标签会成为补全种子。全部为“未分类”的点云仍可按高度阈值生成基础 PGM，但不会触发语义空洞估计。

### 页面打开后样式或三维视图缺失

确认浏览器能够访问页面头部声明的 CDN，并优先通过本地 HTTP 服务打开页面。开发者控制台中的网络错误通常可以指出未加载的 React、Three.js 或 Babel 资源。

### STL 坑洞多或平地变成波浪面

依次检查：

1. 点云是否只覆盖单侧表面，或存在大面积遮挡和缺失。
2. 是否同时包含薄地面的上下两层，但法向被统一指向同一半球。
3. 体素尺寸是否过大，Poisson depth 或目标三角形数是否过低。
4. 是否在简化后继续平滑，导致台阶和薄板塌缩。
5. 尝试先分离地面/墙体、修复法向，或改用 Ball Pivoting 保留真实开口。

点云缺失区域没有唯一正确几何，工具无法凭空恢复原始 CAD。要求无孔、尺寸精确且适合作为 collision 时，应优先使用 STEP/CAD，或在 Blender、MeshLab、CloudCompare 等网格工具中人工修复后再验收。

### STEP 转换被系统终止或长时间无响应

降低最终采样点数通常不能解决 CAD 导入阶段的内存问题。优先增大线性偏差、拆分装配、移除小零件，或先在 CAD 软件中导出 STL/OBJ；确认后端日志中没有触发内存上限。

## 安全与限制

- 地图生成结果必须结合原始点云、赛场测量和 RViz 覆盖结果人工验收。
- 自动语义和空洞估计不会替代人工确认，尤其是坡面边缘、台阶、墙后和遮挡区域。
- 后端默认请求体上限为 1 GiB，只应监听 localhost。
- 当前工具面向离线地图制作，不会发布 ROS topic，也不会修改 Nav2 或 ROGMap 的运行参数。
- 页面中的撤销历史深度有限，关键阶段应及时导出处理后的 PCD 和工程审计 JSON。
