# ROGMap 动态 3D 感知 + 2D 地形距离场改造结果

## 完成状态

本次改造按 `task.md` 的 8 个总目标完成了第一阶段可编译闭环。ROGMap 端 2D layer/field/query 架构已建立，planner 关键搜索、碰撞检查、走廊生成和 MINCO 优化路径通过 `MapQueryInterface` 读取 ROGMap 生成的二维层与 2D ESDF，不直接访问 ROGMap 内部 buffer。Nav2 global planner 插件外壳仍保留用于现有系统接入，但核心规划查询链路不再回退读取 Nav2 costmap。

1. ROGMap 保留并继续维护局部 3D Occupancy Grid。
2. 新增 `ProjectionLayer`，从 3D occupancy 做 z-column 高程分析，生成二维语义层。
3. 二维层输出 `value` cost buffer 和 `mask`，其中 `mask=0` 为 obstacle seed，`mask=1` 为 free/passable。
4. `small_rog_map::DynamicLayer` 增加 `updateFromMask()` 和统一 `rebuild()`，ROGMap 内部也新增同等 2D signed distance field。
5. ROGMap 每次更新后由二维 mask 生成 2D signed distance field，并通过 `evaluate(pos, dist, grad)` 查询距离和梯度。
6. Planner 新增 `MapQueryInterface` 读取路径，支持显式 `setMap()` 注入和 registry 获取 ROGMap 查询接口，不直接访问 ROGMap 内部 buffer；搜索开始时会复制 cost buffer，避免 ROGMap sliding/refresh 时裸指针失效。
7. 未实现动态障碍聚类、Kalman/track id/速度估计。
8. 未添加轮速接口，未修改 LIO/Estimator 状态量。

## 关键改动

ROGMap:

- 新增 `map_query_interface.hpp`：泛化只读地图接口。
- 新增 `map_registry.hpp/.cpp`：进程内过渡 registry。
- 新增 `projection_layer.hpp/.cpp`：二维 z-column 投影/高程语义层。
- 新增 `field_layer.hpp/.cpp`：二维 signed ESDF field。
- 新增 `query_adapter.hpp/.cpp`：snapshot + field 的只读 adapter。
- `MapQueryInterface` 保留 `values()`，并新增 `copyValues()` 安全复制接口；A*/SMAC 规划开始时通过 snapshot 拷贝 cost buffer，避免刷新时裸指针悬空。
- `QueryAdapter::evaluate()` 直接使用 snapshot 内的 distance field 做双线性 distance/gradient 查询，避免 value buffer 和 ESDF 在 ROGMap sliding/refresh 时错位。
- 修改 `prob_map.*`：增加 `last_hit_time_`、`last_update_time_`、active list 和 `applyDecay()`。
- 修改 `rog_map.*`：更新主流程为 3D occupancy -> decay -> 2D layer -> field -> query snapshot。
- 修改 `rog_map_ros2.hpp`：ROS callback 也走统一更新路径，并新增 `/rog_map/layer/value`、`/rog_map/layer/type`、`/rog_map/layer/height`、`/rog_map/field/points` debug topic。

Minco planner:

- 修改 `small_rog_map::DynamicLayer`：增加 `updateFromMask()`，旧点云更新复用统一 `rebuild()`。
- 修改 SMAC、A*、MINCO optimizer、corridor、collision check：有 `MapQueryInterface` 时优先走 ROGMap 查询接口。
- 新增 `MincoPlanner::setMap()` 显式注入入口；无 Nav2 costmap 时可通过 `global_frame` 参数和 odom 缓存获取当前机器人 pose。
- 移除 planner 对 `/global_costmap/voxel_grid` 的动态 ESDF 订阅调用；旧 `HybridESDFMap` 仅作为静态 PCD ESDF fallback。
- `minco_planner` 增加 `rog_map` package 依赖。

## 当前验证说明

已完成定向编译验证：

```bash
colcon build --packages-select rog_map minco_planner --cmake-args -DCMAKE_BUILD_TYPE=Release
```

结果：`rog_map` 和 `minco_planner` 均编译通过。

本轮修复与复核点：

- 在 `minco_planner.cpp` 顶部新增了 `isLineFree(MapQueryInterface)` 前置声明。
- 该 helper 现在能被 `ReplanLocal()` 的 lambda 正常解析，不再触发 `defined but not used`。
- 复核时额外修复了 `values()` 裸指针跨刷新可能悬空的问题：SMAC 和原 A* 改为通过 `copyValues()` 从 snapshot 复制 cost buffer。
- `QueryAdapter::evaluate()` 改为查询 snapshot distance field，保证 distance/gradient 与 snapshot 元数据一致。
- 补充 `MincoPlanner::setMap()`，方便同一 component/main 显式依赖注入，减少对过渡 registry 的依赖。
- `MincoPlanner::configure()` 不再无条件解引用 `costmap_ros_`；没有 Nav2 costmap 时使用 `global_frame` 参数。
- `MincoPlanner::getRobotPose()` 在无 Nav2 costmap 时从 odom 缓存读取 pose，并在 TF 可用时转换到 `global_frame_`。

## 阶段审计

- 阶段 1：ROGMap package 已有 `rog_map::DynamicLayer` 和 `rog_map::ESDFUtils`，支持 `updateFromMask()`、`rebuild()` 和 `evaluate()`；planner 原 `small_rog_map::DynamicLayer` 也保留点云接口并新增 mask 更新接口。
- 阶段 2：`ProjectionLayer` 已实现 UNKNOWN/FREE/PASSABLE/OCCUPIED 分类，输出 `value` 和 `mask`，并支持 height/ratio/timestamp 字段。
- 阶段 3：`ProbMap` 已增加 hit/update timestamp、active list、`applyDecay()`；hit/miss/decay 状态变化复用 `updateCellState()` 通知 inflation/ESDF/frontier。
- 阶段 4：`ROGMap::updateMapInternal()` 已串联 robot state、3D occupancy、decay、2D layer、2D field 和 query snapshot refresh。
- 阶段 5：`ROGMap` 暴露 `getQueryInterface()`，`MapRegistry` 支持进程内过渡获取，`MincoPlanner::setMap()` 支持显式注入。
- 阶段 6：A*、SMAC、corridor、collision check 和 MINCO optimizer 主路径均通过 `MapQueryInterface` 查询地图；不再订阅 `/global_costmap/voxel_grid` 作为动态 ESDF 输入。
- 阶段 7：已发布 value/type OccupancyGrid 和 height/field PointCloud2 debug topic；这些 topic 只用于可视化，不作为 planner 主链路。
