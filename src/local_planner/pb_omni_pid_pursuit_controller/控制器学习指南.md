# ROS2 Nav2 自定义控制器开发完整指南

## 📚 概述

这份指南基于 `pb_omni_pid_pursuit_controller` 的详细分析，帮助您学习如何开发自己的 Nav2 控制器。

## 🏗️ 控制器架构概览

### 1. 核心继承关系
```cpp
class OmniPidPursuitController : public nav2_core::Controller
```

- **基类**: `nav2_core::Controller` 是 Nav2 控制器的标准接口
- **插件机制**: 使用 `pluginlib` 实现动态加载
- **生命周期管理**: 继承 ROS2 生命周期节点的管理机制

### 2. 关键组件
- **TF变换缓冲区** (`tf2_ros::Buffer`): 处理坐标系转换
- **代价地图接口** (`nav2_costmap_2d::Costmap2DROS`): 环境感知和碰撞检测
- **PID控制器** (`PID`): 实现速度控制逻辑
- **发布者** (`rclcpp_lifecycle::LifecyclePublisher`): 可视化和调试

## 🔄 生命周期节点详解

Nav2 控制器遵循 ROS2 生命周期节点模式，确保资源管理的安全性：

### 状态转换图
```
Unconfigured ──configure()──> Inactive ──activate()──> Active
     ↑              │               ↑            │        │
     │         cleanup()          │     deactivate()    │
     └──────────────────────────────┘                  │
                                                       │
    ←──────────────── deactivate() + cleanup() ←───────┘
```

### 各阶段职责

#### 1. `configure()` 阶段 - 资源准备
```cpp
void configure(
  const rclcpp_lifecycle::LifecycleNode::WeakPtr & parent,
  std::string name,
  std::shared_ptr<tf2_ros::Buffer> tf,
  std::shared_ptr<nav2_costmap_2d::Costmap2DROS> costmap_ros
) override;
```

**输入参数说明：**
- `parent`: 生命周期节点的弱引用，避免循环引用
- `name`: 插件名称，用于参数命名空间
- `tf`: TF变换缓冲区，处理坐标系转换
- `costmap_ros`: 代价地图ROS接口，提供环境信息

**主要任务：**
1. 参数声明和读取
2. 创建发布者（但不激活）
3. 初始化内部组件（PID控制器等）
4. 验证配置的有效性

#### 2. `activate()` 阶段 - 开始工作
- 激活所有发布者
- 注册动态参数回调
- 初始化跟踪状态变量

#### 3. `deactivate()` 阶段 - 暂停工作
- 停用发布者
- 取消参数回调注册
- 保留配置信息

#### 4. `cleanup()` 阶段 - 资源释放
- 重置所有智能指针
- 清理临时数据
- 准备重新配置或销毁

## 🎯 核心算法实现: computeVelocityCommands()

这是控制器的心脏函数，Nav2会以配置的频率（通常20Hz）调用它：

### 函数签名
```cpp
geometry_msgs::msg::TwistStamped computeVelocityCommands(
  const geometry_msgs::msg::PoseStamped & pose,      // 当前位姿
  const geometry_msgs::msg::Twist & velocity,        // 当前速度
  nav2_core::GoalChecker * goal_checker              // 目标检查器
) override;
```

### 算法流程详解

#### 步骤1: 坐标变换
```cpp
auto transformed_plan = transformGlobalPlan(pose);
```
- **目的**: 将全局路径转换到机器人本体坐标系
- **优势**: 简化后续的距离和角度计算
- **实现**: 使用TF变换，处理不同坐标系之间的转换

#### 步骤2: 自适应前瞻距离
```cpp
double lookahead_dist = getLookAheadDistance(velocity);
```
- **Pure Pursuit核心**: 前瞻距离决定机器人的"视野"
- **自适应策略**: `lookahead_dist = velocity * lookahead_time`
- **边界约束**: `[min_lookahead_dist, max_lookahead_dist]`

#### 步骤3: 目标点选择
```cpp
auto carrot_pose = getLookAheadPoint(lookahead_dist, transformed_plan);
```
- **Carrot Point**: 路径上距离机器人前瞻距离的点
- **插值优化**: 使用圆-线段交点精确计算
- **几何原理**: 在本体坐标系中，以原点为圆心，前瞻距离为半径的圆与路径的交点

#### 步骤4: PID控制计算
```cpp
// 计算到目标点的距离和方向
double lin_dist = hypot(carrot_pose.pose.position.x, carrot_pose.pose.position.y);
double theta_dist = atan2(carrot_pose.pose.position.y, carrot_pose.pose.position.x);
double angle_to_goal = tf2::getYaw(carrot_pose.pose.orientation);

// 双PID控制
auto lin_vel = move_pid_->calculate(lin_dist, 0);
auto angular_vel = enable_rotation_ ? heading_pid_->calculate(angle_to_goal, 0) : 0.0;
```

**PID控制策略：**
- **线性PID**: 控制到目标点的距离 → 线性速度
- **角度PID**: 控制朝向误差 → 角速度
- **期望值**: 都设为0（期望距离为0，期望角度误差为0）

#### 步骤5: 约束应用
```cpp
// 曲率限制（防止急转弯时速度过快）
applyCurvatureLimitation(transformed_plan, carrot_pose, lin_vel);
// 接近目标时减速
applyApproachVelocityScaling(transformed_plan, lin_vel);
```

#### 步骤6: 全向轮运动分解
```cpp
// 全向轮可以实现任意方向的运动
cmd_vel.twist.linear.x = lin_vel * cos(theta_dist);   // 前后分量
cmd_vel.twist.linear.y = lin_vel * sin(theta_dist);   // 左右分量  
cmd_vel.twist.angular.z = angular_vel;                // 旋转分量
```

## 🔧 关键参数配置指南

### PID参数调优
```yaml
translation_kp: 3.0    # 比例增益，影响响应速度
translation_ki: 0.1    # 积分增益，消除稳态误差
translation_kd: 0.3    # 微分增益，减少超调

rotation_kp: 3.0       # 角度比例增益
rotation_ki: 0.1       # 角度积分增益  
rotation_kd: 0.3       # 角度微分增益
```

**调优建议：**
1. 先调Kp，观察响应速度和稳定性
2. 如有稳态误差，适当增加Ki
3. 如有振荡，适当增加Kd
4. 角度控制通常需要更高的Kp

### Pure Pursuit参数
```yaml
lookahead_dist: 0.3              # 基础前瞻距离
use_velocity_scaled_lookahead_dist: true  # 启用速度自适应
min_lookahead_dist: 0.2          # 最小前瞻距离
max_lookahead_dist: 1.0          # 最大前瞻距离
lookahead_time: 1.0              # 前瞻时间常数
```

**调优原则：**
- 前瞻距离越大，路径越平滑，但转弯响应越慢
- 前瞻距离越小，转弯越灵敏，但可能产生振荡
- 建议根据机器人尺寸和运动特性调整

### 安全和性能参数
```yaml
# 速度限制
v_linear_max: 3.0     # 最大线性速度
v_angular_max: 3.0    # 最大角速度

# 接近目标时的减速
approach_velocity_scaling_dist: 0.6    # 开始减速的距离
min_approach_linear_velocity: 0.05     # 最小接近速度

# 曲率限制（防止急转弯时速度过快）
curvature_min: 0.4    # 开始限速的曲率阈值
curvature_max: 0.7    # 最大限速的曲率阈值
reduction_ratio_at_high_curvature: 0.5  # 高曲率时的速度削减比例
```

### 2. 基本文件模板

#### package.xml
```xml
<?xml version="1.0"?>
<package format="3">
  <name>your_controller</name>
  <version>1.0.0</version>
  <description>Your custom Nav2 controller</description>
  
  <buildtool_depend>ament_cmake</buildtool_depend>
  
  <depend>rclcpp</depend>
  <depend>rclcpp_lifecycle</depend>
  <depend>nav2_core</depend>
  <depend>nav2_costmap_2d</depend>
  <depend>nav2_util</depend>
  <depend>geometry_msgs</depend>
  <depend>nav_msgs</depend>
  <depend>tf2_ros</depend>
  <depend>pluginlib</depend>
  
  <export>
    <build_type>ament_cmake</build_type>
    <!-- 重要：声明这是一个插件包 -->
    <nav2_core plugin="${prefix}/your_controller.xml" />
  </export>
</package>
```

#### your_controller.xml (插件描述)
```xml
<library path="your_controller">
  <class type="your_namespace::YourController" base_class_type="nav2_core::Controller">
    <description>Your custom controller description</description>
  </class>
</library>
```

### 3. CMakeLists.txt 配置
```cmake
cmake_minimum_required(VERSION 3.5)
project(your_controller)

# 编译设置
set(CMAKE_CXX_STANDARD 17)
if(CMAKE_COMPILER_IS_GNUCXX OR CMAKE_CXX_COMPILER_ID MATCHES "Clang")
  add_compile_options(-Wall -Wextra -Wpedantic)
endif()

# 依赖包
find_package(ament_cmake REQUIRED)
find_package(rclcpp REQUIRED)
find_package(rclcpp_lifecycle REQUIRED)
find_package(nav2_core REQUIRED)
find_package(nav2_costmap_2d REQUIRED)
find_package(nav2_util REQUIRED)
find_package(geometry_msgs REQUIRED)
find_package(nav_msgs REQUIRED)
find_package(tf2_ros REQUIRED)
find_package(pluginlib REQUIRED)

set(dependencies
  rclcpp
  rclcpp_lifecycle
  nav2_core
  nav2_costmap_2d
  nav2_util
  geometry_msgs
  nav_msgs
  tf2_ros
  pluginlib
)

# 创建库
add_library(${PROJECT_NAME} SHARED
  src/your_controller.cpp
)

# 包含目录
target_include_directories(${PROJECT_NAME}
  PUBLIC
    $<BUILD_INTERFACE:${CMAKE_CURRENT_SOURCE_DIR}/include>
    $<INSTALL_INTERFACE:include>
)

# 链接依赖
ament_target_dependencies(${PROJECT_NAME} ${dependencies})

# 安装
install(TARGETS ${PROJECT_NAME}
  ARCHIVE DESTINATION lib
  LIBRARY DESTINATION lib
  RUNTIME DESTINATION bin
)

install(DIRECTORY include/
  DESTINATION include/
)

# 插件描述文件
install(FILES your_controller.xml
  DESTINATION share/${PROJECT_NAME}
)

# 导出插件
pluginlib_export_plugin_description_file(nav2_core your_controller.xml)

ament_export_include_directories(include)
ament_export_libraries(${PROJECT_NAME})
ament_export_dependencies(${dependencies})

ament_package()
```
